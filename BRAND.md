# Saarthi Telematics artwork

The owner supplied `public/brand/source.jpeg` on 6 October 2026. The shield and
lettering are used without redrawing. The horizontal header combines crops of
that source; opening screens and social previews use the complete artwork.

Use the shield for compact icons and a white backing to preserve contrast for
the navy mark. All web artwork lives in `public/brand/`; the shared Logo component
renders the header/footer lockup. Favicons, touch icons, web manifest icons and
Open Graph preview use the same identity.

The full regeneration script is maintained at `design_system/brand/generate.py`
in the Saarthi multi-app workspace. Source artwork is also retained here so this
website can be maintained independently.
